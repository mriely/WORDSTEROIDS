# WORDSTEROIDS

Single-page HTML/JS game. Entry point: `wordsteroids.html`. Game code lives in `js/` (engine, render, entities, words, audio, net).

## Before pushing

**Bump the version number.** It is displayed in the HUD and lives in [wordsteroids.html:22](wordsteroids.html#L22) as `// prototype build X.Y`. Increment it on every push so players can tell which build they're on.
